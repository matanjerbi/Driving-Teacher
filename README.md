# ניר הלאלי – לימוד נהיגה על אופנועים

אתר סטטי לבית ספר לנהיגה על אופנועים בפתח תקווה (רישיון A2 · A1 · A).

- `index.html` – דף הבית: דרגות רישיון, תהליך, ביקורות, שאלות נפוצות, יצירת קשר.
- `guide.html` – "כמה שיעורים אני צריך?": אשף שמציג את המסלול לפי הרישיון הרצוי והרישיון הקיים, טבלת דרגות והסבר על הטופס הירוק.

אין תלות בבנייה – אפשר לפתוח ישירות בדפדפן או לפרוס כמו שהוא (למשל Cloudflare Pages / GitHub Pages).
